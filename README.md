# FGO Voice Autofill

FGO風の台詞テンプレートへ、入力した台詞を自動配置して@wiki記法を生成するツールです。

## 主な機能

- 通常台詞を `#region(close,セリフ一覧)` として生成
- 「差分を追加」ボタンで差分台詞ブロックを必要数だけ追加
- 差分ブロック名を自由に変更
- 召喚 / 仮加入 / 本加入に対応
- My room の会話は初期3件で、「会話を追加」から必要数だけ追加
- Synthesis の「霊基再臨4」の下に「霊衣解放」を配置し、「霊衣解放を追加」から2件目以降を追加
- My room の「聖杯について」の下に「霊衣について」を配置し、「霊衣についてを追加」から2件目以降を追加
- 各会話に関連サーヴァントを指定し、`（[[〇〇]]所属時）` / `（[[〇〇>〇〇/セイバー]]所属時）` を自動付与
- 通常・差分とも未入力の台詞行を生成しない
- そのセクションに入力が1件もなければ Grand summon / Synthesis / Battle / My room の見出しも生成しない
- 空の差分ブロックは生成しない
- 三点リーダーを `……` に統一
- ダッシュを `――` に統一
- 半角 `!` / `?` を全角 `！` / `？` に統一
- 感嘆符・疑問符が文末でない場合、後ろへ半角空白を自動挿入
- 複数行入力を `&br()` へ変換
- @wiki表を壊す `|` を `&#124;` へ退避
- 生成結果のコピー
- `localStorage` による入力内容・追加行数・差分の保存/復元

## 動的追加項目

### 会話

初期状態では会話1～3を表示します。「会話を追加」を押すたびに会話4、5、6……を追加します。

### 霊衣解放

Synthesis の霊基再臨4の直後に霊衣解放1を表示します。「霊衣解放を追加」を押すたびに2、3、4……を追加します。

```text
|霊衣解放|1|台詞1|
|~|2|台詞2|
```

### 霊衣について

My room の聖杯についての直後に霊衣について1を表示します。「霊衣についてを追加」を押すたびに2、3、4……を追加します。

```text
|霊衣について|1|台詞1|
|~|2|台詞2|
```

いずれも追加済みでも未入力の行は生成しません。

## 関連サーヴァント

My room の各「会話」には「関連サーヴァント（任意）」欄があります。

`〇〇` と入力すると `台詞（[[〇〇]]所属時）`、`〇〇>〇〇/セイバー` と入力すると `台詞（[[〇〇>〇〇/セイバー]]所属時）` を生成します。

`[[〇〇]]` のようにリンク記法込みで入力しても二重括弧にはしません。会話本文が空欄なら、関連サーヴァントだけを入力してもその行は生成しません。

## 未入力行の扱い

通常・差分を問わず、台詞が未入力の行は生成しません。同じ種類の台詞が複数入力されている場合、2行目以降は `~` を使います。

Grand summon / Synthesis / Battle / My room も、そのセクション内に使用中の台詞がなければ見出しごと生成しません。

## 自動整形

- `...` / `…` / `・・・` → `……`
- `--` / `—` / `―` → `――`
- `!` → `！`
- `?` → `？`
- 文中の `！` / `？` の直後 → 半角空白1つ

閉じ括弧だけが後ろに続いて行末になる場合は文末として扱い、不要な空白を挿入しません。

## 保存データ

入力内容、追加した差分、会話・霊衣解放・霊衣についての追加件数を `localStorage` に保存します。

v2.x以前の保存データも移行します。旧差分側の単独「霊衣について」は新しい「霊衣について1」へ自動移行します。

## @wikiへの導入

1. @wikiで専用ページを作成します。
2. ページを「管理者のみ編集可能」にします。
3. `atwiki_paste.txt` の内容をそのまま貼り付けます。
4. 保存すると入力フォームが表示されます。
