# FGO Voice Autofill

FGO風の台詞テンプレートへ、入力した台詞を自動配置して@wiki記法を生成するツールです。

## 主な機能

- 通常台詞を `#region(close,セリフ一覧)` として生成
- 「差分を追加」ボタンで差分台詞ブロックを必要数だけ追加
- 差分ブロック名を自由に変更
- 召喚 / 仮加入 / 本加入に対応
- 通常・差分とも未入力の台詞行を生成しない
- そのセクションに入力が1件もなければ Grand summon / Synthesis / Battle / My room の見出しも生成しない
- 空の差分ブロックは生成しない
- 差分ブロックでは「霊衣について」も任意入力可能
- 三点リーダーを `……` に統一
- ダッシュを `――` に統一
- 半角 `!` / `?` を全角 `！` / `？` に統一
- 感嘆符・疑問符が文末でない場合、後ろへ半角空白を自動挿入
- 複数行入力を `&br()` へ変換
- @wiki表を壊す `|` を `&#124;` へ退避
- 生成結果のコピー
- `localStorage` による入力内容の保存・復元
- v1.xの「真名判明時」保存データを差分ブロックへ移行

## @wikiへの導入

1. @wikiで、この機能を置く専用ページを作成します。
2. ページの編集権限を「管理者のみ編集可能」にします。
3. `atwiki_paste.txt` の内容をそのまま貼り付けます。
4. 保存すると入力フォームが表示されます。

## 出力形式

通常台詞は次の形式で生成します。

```text
#region(close,セリフ一覧)
|BGCOLOR(#F5FFFA):CENTER:110|BGCOLOR(#F5FFFA):CENTER:40|BGCOLOR(#F5FFFA):LEFT:1000|c
...
#endregion()
```

差分台詞は「差分を追加」で作成し、入力したブロック名を使って別regionとして生成します。

```text
#region(close,第3再臨以降)
...
#endregion()
```

差分数に上限は設けていません。完全に空の差分は生成されません。

## 未入力行の扱い

通常・差分を問わず、台詞が未入力の行は生成しません。たとえば「スキル2」だけ入力した場合、出力されるのは次の行だけです。

```text
|スキル|2|台詞|
```

同じ種類の台詞が複数入力されている場合、2行目以降は `~` を使います。

```text
|スキル|2|台詞2|
|~|4|台詞4|
```

Grand summon / Synthesis / Battle / My room も、そのセクション内に使用中の台詞がなければ見出しごと生成しません。

## 自動整形

以下を自動変換します。

- `...` / `…` / `・・・` → `……`
- `--` / `—` / `―` → `――`
- `!` → `！`
- `?` → `？`
- 文中の `！` / `？` の直後 → 半角空白1つ

閉じ括弧だけが後ろに続いて行末になる場合は文末として扱い、不要な空白を挿入しません。

## 保存データ

入力内容と追加した差分ブロックはブラウザの `localStorage` へ保存できます。

v1.xで保存していた通常台詞は通常ブロックへ、旧「真名判明時」台詞は「真名判明時」という名称の差分ブロックへ自動移行します。
