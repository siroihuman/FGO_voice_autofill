# FGO Voice Autofill

FGO風の台詞テンプレートへ、入力した台詞を自動配置して@wiki記法を生成するツールです。

## 主な機能

- 通常台詞を `#region(close,セリフ一覧)` として生成
- 「差分を追加」ボタンで差分台詞ブロックを必要数だけ追加
- 差分ブロック名を自由に変更
- 召喚 / 仮加入 / 本加入に対応
- 通常・差分とも未入力の台詞行を生成しない
- 使用中の台詞がなければ Grand summon / Synthesis / Battle / My room の見出しも生成しない
- My room の「会話」は初期3件で、「会話を追加」から必要数だけ追加
- 各会話の「関連サーヴァント（任意）」は初期1件で、「関連サーヴァントを追加」から必要数だけ追加
- 関連サーヴァントを複数指定した場合、@wikiリンクを全角読点 `、` で連結して `（[[A]]、[[B]]所属時）` の形式で台詞末尾へ追加
- `〇〇>〇〇/セイバー` のような表示名とリンク先を分ける@wiki形式に対応
- `[[〇〇]]` のようにリンク記法込みで入力しても二重括弧にしない
- Synthesis の「霊基再臨4」下に「霊衣解放」を配置し、追加ボタンで複数化
- My room の「聖杯について」下に「霊衣について」を配置し、追加ボタンで複数化
- 三点リーダーを `……` に統一
- ダッシュを `――` に統一
- 半角 `!` / `?` を全角 `！` / `？` に統一
- 感嘆符・疑問符が文末でない場合、後ろへ半角空白を自動挿入
- 複数行入力を `&br()` へ変換
- @wiki表を壊す `|` を `&#124;` へ退避
- 生成結果のコピー
- `localStorage` による入力内容・追加行数・差分ブロックの保存と復元
- v1～v3の保存データを現在形式へ移行

## @wikiへの導入

1. @wikiで、この機能を置く専用ページを作成します。
2. ページの編集権限を「管理者のみ編集可能」にします。
3. `atwiki_paste.txt` の内容をそのまま貼り付けます。
4. 保存すると入力フォームが表示されます。

## 関連サーヴァント

My room の各「会話」には関連サーヴァントを指定できます。

1件の場合:

```text
入力: 〇〇
出力: 台詞（[[〇〇]]所属時）
```

リンク先を明示する場合:

```text
入力: 〇〇>〇〇/セイバー
出力: 台詞（[[〇〇>〇〇/セイバー]]所属時）
```

複数指定する場合は「関連サーヴァントを追加」を押して別々の欄へ入力します。

```text
1: 〇〇>〇〇/セイバー
2: 〇〇>〇〇/キャスター
```

生成結果:

```text
台詞（[[〇〇>〇〇/セイバー]]、[[〇〇>〇〇/キャスター]]所属時）
```

空欄の関連サーヴァント欄は無視します。また、会話本文自体が未入力の場合は関連サーヴァントだけ入力されていてもその会話行を生成しません。

## 動的に追加できる項目

- My room / 会話: 初期3件
- 各会話 / 関連サーヴァント: 初期1件
- Synthesis / 霊衣解放: 初期1件
- My room / 霊衣について: 初期1件
- 差分台詞ブロック: 初期0件

追加した件数はブラウザに保存され、次回復元されます。

## 未入力行の扱い

通常・差分を問わず、台詞が未入力の行は生成しません。同じ種類の台詞が複数入力されている場合、2行目以降は `~` を使います。

## 自動整形

以下を自動変換します。

- `...` / `…` / `・・・` → `……`
- `--` / `—` / `―` → `――`
- `!` → `！`
- `?` → `？`
- 文中の `！` / `？` の直後 → 半角空白1つ

閉じ括弧だけが後ろに続いて行末になる場合は文末として扱い、不要な空白を挿入しません。
