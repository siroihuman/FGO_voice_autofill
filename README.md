# FGO Voice Autofill

FGO風の台詞テンプレートへ、入力した台詞を自動配置して@wiki記法を生成するツールです。

## 主な機能

- 指定された「セリフ一覧」テンプレートを自動生成
- 通常台詞と「真名判明時」の台詞を個別入力
- 真名判明時ブロックを有効化 / `#co()` 内へ格納の切り替え
- 三点リーダーを `……` に統一
- ダッシュを `――` に統一
- 半角 `!` / `?` を全角 `！` / `？` に統一
- 感嘆符・疑問符が文末でない場合、後ろへ半角空白を自動挿入
- 複数行入力を `&br()` へ変換
- @wiki表を壊す `|` を `&#124;` へ退避
- 生成結果のコピー
- `localStorage` による入力内容の保存・復元

## @wikiへの導入

1. @wikiで、この機能を置く専用ページを作成します。
2. ページの編集権限を「管理者のみ編集可能」にします。
3. `atwiki_paste.txt` の内容をそのまま貼り付けます。
4. 保存すると入力フォームが表示されます。

## 自動整形

入力例：

```text
えっ!?本当に...?
```

生成時：

```text
えっ！？ 本当に……？
```

以下を自動変換します。

- `...` / `…` / `・・・` → `……`
- `--` / `—` / `―` → `――`
- `!` → `！`
- `?` → `？`
- 文中の `！` / `？` の直後 → 半角空白1つ

閉じ括弧だけが後ろに続いて行末になる場合は文末として扱い、不要な空白を挿入しません。

## 真名判明時

「真名判明時の台詞を有効化する」をONにすると、`#region(close,真名判明時)` を通常の有効な記述として生成します。

OFFの場合は、元テンプレートどおり `#co(){{{{{ ... }}}}}` の内側へ真名判明時ブロックを格納します。

真名判明時には通常項目に加えて「霊衣について」を入力できます。
