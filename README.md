# FGO Voice Autofill

FGO風の台詞テンプレートへ、入力した台詞を自動配置して@wiki記法を生成するツールです。

## 主な機能

- 通常台詞を `#region(close,セリフ一覧)` として生成
- 「差分を追加」ボタンで差分台詞ブロックを必要数だけ追加
- 差分ブロック名を自由に変更
- 召喚 / 仮加入 / 本加入に対応
- 通常・差分とも未入力の台詞行を生成しない
- そのセクションに入力が1件もなければ Grand summon / Synthesis / Battle / My room の見出しも生成しない
- 空の差分ブロックは生成しない
- 差分ブロックでは「霊衣について」も任意入力可能
- My room の「会話」は初期3件で、「会話を追加」から必要数だけ増加
- 各「会話」に関連サーヴァントを指定し、所属条件リンクを台詞末尾へ自動付与
- 三点リーダーを `……` に統一
- ダッシュを `――` に統一
- 半角 `!` / `?` を全角 `！` / `？` に統一
- 感嘆符・疑問符が文末でない場合、後ろへ半角空白を自動挿入
- 複数行入力を `&br()` へ変換
- @wiki表を壊す `|` を `&#124;` へ退避
- 生成結果のコピー
- `localStorage` による入力内容・差分数・会話追加数の保存と復元
- v1.xの「真名判明時」保存データを差分ブロックへ移行

## @wikiへの導入

1. @wikiで、この機能を置く専用ページを作成します。
2. ページの編集権限を「管理者のみ編集可能」にします。
3. `atwiki_paste.txt` の内容をそのまま貼り付けます。
4. 保存すると入力フォームが表示されます。

## 未入力行の扱い

通常・差分を問わず、台詞が未入力の行は生成しません。同じ種類の台詞が複数入力されている場合、2行目以降は `~` を使います。

Grand summon / Synthesis / Battle / My room も、そのセクション内に使用中の台詞がなければ見出しごと生成しません。

## My room の会話

会話欄は各ブロックにつき初期状態で1～3まで表示します。「会話を追加」を押すたびに4、5、6……と増やせます。

追加した会話数も保存されます。旧版で会話4以降に実際の入力が残っている場合は、その最大番号まで自動復元します。

### 関連サーヴァント

各会話には「関連サーヴァント（任意）」欄があります。

サーヴァント名だけを入力した場合：

```text
〇〇
```

生成結果：

```text
台詞（[[〇〇]]所属時）
```

表示名と遷移先を分けたい場合：

```text
〇〇>〇〇/セイバー
```

生成結果：

```text
台詞（[[〇〇>〇〇/セイバー]]所属時）
```

`[[〇〇]]` のようにリンク記法ごと入力しても二重括弧にはなりません。会話本文が空の場合、関連サーヴァントだけを入力してもその会話行は生成しません。

## 自動整形

以下を自動変換します。

- `...` / `…` / `・・・` → `……`
- `--` / `—` / `―` → `――`
- `!` → `！`
- `?` → `？`
- 文中の `！` / `？` の直後 → 半角空白1つ

閉じ括弧だけが後ろに続いて行末になる場合は文末として扱い、不要な空白を挿入しません。

## 保存データ

入力内容と追加した差分ブロック、会話追加数、関連サーヴァント指定はブラウザの `localStorage` へ保存できます。

v1.xで保存していた通常台詞は通常ブロックへ、旧「真名判明時」台詞は「真名判明時」という名称の差分ブロックへ自動移行します。
